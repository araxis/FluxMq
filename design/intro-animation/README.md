# FluxMQ Remotion Videos

Remotion compositions for early FluxMQ product motion.

## Render

```powershell
cd design/intro-animation
npm install
npm run render
npm run render:ad
npm run still
npm run still:ad
```

Outputs:

- `out/fluxmq-intro.mp4`
- `out/fluxmq-intro-poster.png`
- `out/fluxmq-ad.mp4`
- `out/fluxmq-ad-poster.png`

## Intro Concept

The animation introduces FluxMQ as an MQTT debugging and observability workspace:

1. Signal pulse and topic graph.
2. Live message stream.
3. Payload inspection and diff.
4. Observability timeline and replay.
5. Final product lockup.

## Two-Minute Ad Concept

`FluxMqAd` is a 120-second captioned product ad based on the project memory:

1. Problem hook: passive MQTT viewers are not enough.
2. FluxMQ reveal: a runtime-powered MQTT debugging and observability workbench.
3. Workspace proof: topic explorer, live messages, and source-agnostic data paths.
4. Payload proof: decoding, diffing, and schema validation.
5. Replay proof: recorded sessions and controlled replay.
6. Runtime proof: sources, filters, dynamic mappers, validators, actors, observers.
7. Ops/QA proof: metrics, assertions, and scenario testing.
8. Final lockup: "Debug MQTT streams like production systems."

See `FluxMqAd-script.md` for the voiceover and scene timing.
