# Logs And Topics

Logs and topics are first-class workspace views.

## Logs

The Logs page shows scoped entries from validation, runtime, app execution, and test runs.

Use filters to narrow by:

- scope
- level
- text search

The old right-panel log tab has been removed. The right panel is reserved for live MQTT tools on pipeline and dashboard surfaces.

## Topics

The Topics page gives the topic tree more space than the live side panel. It combines:

- topic hierarchy
- message table
- payload inspector

Live traffic is shown by default. Selecting a stored session switches the topic tree and message table to that session. Selecting a topic branch filters messages to that branch and child topics.
