# FluxMQ

FluxMQ is a desktop workspace for MQTT debugging, workflow design, observability, recording, replay, and integration checks.

The documentation site is for people using the application. Contributor and architecture material stays in the repository developer documentation.

## Core Workflows

- Define app-level broker resources.
- Design pipelines from sources, filters, mappers, routers, observers, and actors.
- Publish test traffic from the live tools panel while checking a pipeline or dashboard.
- Explore live and stored topic trees.
- Build dashboards from event counters, latest-event cards, and event-rate widgets.
- Run test scenarios that use normal MQTT publish/trigger steps plus event expectations.
- Record and replay MQTT sessions through explicit workflow components.
